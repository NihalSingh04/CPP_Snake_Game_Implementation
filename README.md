# Snake Game in C++

A simple Snake Game built using **C++** that runs in the terminal/console.

## Features

- Move the snake using the keyboard.
- Eat food to increase your score.
- Snake grows after eating food.
- Game ends if the snake hits the wall or its own tail.
- Three difficulty levels:
  - Easy
  - Medium
  - Hard

## Controls

| Key | Action |
|------|--------|
| W | Move Up |
| A | Move Left |
| S | Move Down |
| D | Move Right |
| X | Exit Game |

## How to Run

### Compile

Using g++:

```bash
g++ snake.cpp -o snake
```

### Run

#### Windows

```bash
snake.exe
```

#### Linux / macOS

```bash
./snake
```

## Game Rules

- Control the snake using **W, A, S, D**.
- Eat the **#** symbol to gain **10 points**.
- Every time the snake eats food, its tail grows.
- Avoid hitting the walls or your own tail.
- Press **X** anytime to quit.

## Technologies Used

- C++
- Standard Library
- Console-based graphics
